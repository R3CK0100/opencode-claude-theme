# OpenCode Claude Desktop Theme

Tema visual para replicar la interfaz de Claude Desktop en OpenCode Desktop.

## Contenido

- `claude-desktop-theme.css`: Hoja de estilos con la paleta de colores, tipografías y proporciones de Claude.
- `index.html`: Plantilla modificada que incluye el CSS del tema.
- `pack.sh`: Script para empaquetar el asar e instalar el tema en OpenCode.

## Empaquetar e Instalar

```bash
./pack.sh
```
